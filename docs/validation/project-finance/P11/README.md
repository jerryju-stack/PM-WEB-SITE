## 来源和计算

- **设备、产线与模具**使用同一资产标识关联 ME 依据、可识别产线、采购证据和供应商模具报价。资产页分别显示完整毛额、按产品分摊的资本及项目承担的新增现金支出。新增资产付款可分期，付款份额合计为 1。已有共享资产进入分摊资本和全成本折旧。分摊份额小于 1 时，剩余份额属于项目范围之外。新增资产从启用期按直线折旧，于折旧期末纳入残值现金。归档内已资本化的供应商模具保留采购引用，新增模具通过 P08 的资产标识及报价币种、汇率来源取得金额。
- **客户补偿**在同一协议源行记录约定、应收、预计到账和带日期、依据的实际到账。实收占用预计余款，同一到账编号只能采用一次。一次性补偿冲减资本现金支出。件价摊回按指定产品的销量及件价增额计算，累计以合同额封顶，单列发生期和兑现期。若件价已包含于商务报价，补偿协议保留追溯记录，财务影响沿商务输入进入。净资本支出等于采购付款减一次性补偿，残值和件价回款各自列示。
- **营运资金和税**按产品及生效期录入应收、应付、存货天数与 360／365 日基准。一般营业收入计经营应收，材料额计存货与应付，已单独排期的件价增额沿补偿协议兑现。营运资金现金变动为期初减期末余额，可指定期末释放。原生预测按正增量税前利润计税。CQA 延用原表带符号的计税口径。原生模型原有独立现金调整项继续提供其他现金作用，其来源金额应扣除已由 P11 单独建模的部分。
- **回报**用合并后的完整逐期增量现金计算 NPV、IRR、回收期和资金缺口。折现率在回报页可录入并追溯。全成本视图显示全成本利润、全成本折旧及对应的增量利润与折旧。增量视图显示经营资金、税、付款和回款的现金账桥，并从首个资金最低期追到付款或收益源行。页面返回保留期间、产品、版本和源行焦点。
- **P05** 原始投资付款、补偿和已资本化的供应商模具遵循归档来源。归档的分期付款与回款进入生命周期现金。已分摊资本和新增购置的细分数据来自新增的资产记录。利用 Financials 294–300、302、320–323、337–351、426–430 和 Exec Sum 对四产品、11 期的 CNY 与 USD 现金和项目回报逐项复核。源数值保留在授权环境。

## T5 对表

回款延期与购置金额变化分别基于同一冻结起点。合成案例第 0 期支付 ¥10,000，第 1 年原预计收到 ¥10,000，折现率为 10%。资产启用后直线折旧两年，残值及其他现金变化为零。

| 指标 | 只把到账由第 1 年移至第 2 年 | 只把设备购置由 ¥10,000 增至 ¥12,000 |
|---|---:|---:|
| 全期毛投资／采购付款变化 | ¥0 | +¥2,000 |
| 全期补偿约定额／累计回款变化 | ¥0 | ¥0 |
| 净资本支出变化 | ¥0 | +¥2,000 |
| 第 0、1、2 期现金差额 | ¥0、−¥10,000、+¥10,000 | −¥2,000、¥0、¥0 |
| NPV 变化 | −¥826.45 | −¥2,000 |
| 资金缺口峰值 | ¥10,000 → ¥10,000 | ¥10,000 → ¥12,000 |
| 首个资金最低期 | 第 0 期 → 第 0 期 | 第 0 期 → 第 0 期 |
| 回收 | 第 1 年 → 第 2 年 | 第 1 年 → 预测期内未回收 |
| 全成本利润／增量税前利润变化 | 各 ¥0 | 各 −¥2,000 |
