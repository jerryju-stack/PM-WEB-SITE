# P13 · 版本差异、归因与全模块联动

2026-11-18 · 本机技术验证 · 归因版本 P13.1。

在已有项目的 **Project Finance → Version Comparison** 打开 `/projects/:id/finance/compare`。默认比较批准基线和当前预测。Before 和 After 都可独立选择同项目的冻结 CQA、任意阶段版本或草稿。页面显示名称、状态、修订、版本各自的 As of 日期、报告币种及共同估值截止期。可按产品查看，也可交换比较方向。金额差始终为 After − Before。永久链接带上两版、产品、截止期。源行链接还携带记录标识、有效期、原版本和修订。返回恢复原过滤、展开的归因行、页面位置与焦点。直接打开来源也可返回同一对版本。

截止期从共同 Year 0 起覆盖到所选期间，两版先完成原有计划和实际分期计算，再截取已计算现金序列。每个版本的 IRR、回收期、资金峰值用同一口径的完整截取序列求解。NPV 按所选期间直接计算，累计曲线与逐期利润、现金、累计现金和现值同时列出原值、新值和差额。账表沿用 P12 每版已登记的执行截止点和全项目执行口径。财务币种、精度、口径和 Period 0 锚点必须相同。年度从 Year 0 对齐到最长共同前缀，新增或退出的产品用对应一侧的零活动体现。真实缺数保留原状态。

## 金额桥归因

1. 对每个产品、期间、稳定的计算项取得原值和新值。收入按销量与有效单价拆成 `Δ销量 × 原单价`、`原销量 × Δ单价`、`Δ销量 × Δ单价`，按这个顺序展示。市场结构纳入有效销量、加权售价的影响。制造按财务计费人时与费率、工程按分摊且未覆盖的工时与费率使用同一分解。制造人时包含产量、CT、定员、效率或实测口径，CQA 还采用档案的年度人工及负荷因子。定义或来源模式变化造成无法成对的分量留在该业务驱动。
2. 营业、材料、厂费、开发、样机、试验、折旧、件价摊回等按各自的有符号入账额归因。客户补偿及资产采购等现金从发生额分开。现金桥在相同产品、相同费用或协议下，将不同期间的反向现金变动按各自的期间顺序配对。匹配额归属现金时点，未匹配额归属金额。估值截止期之外的腿可用于辨认是哪笔现金移期，金额桥只计入选中截止期以内的腿。
3. 原口径金额变化先用原报告汇率折算，再把报告汇率变化应用到新金额。NPV 将当期现金差按 Before 的折现率折现，再对 After 现金应用新老折现因子差。利率、IRR 和利润率的变化单独用百分点表示。
4. 产品逐期汇总成项目。精确分数逐期核对独立计算的利润差和现值差。若还有差额，桥单列 **Unexplained residual**，并保留可追溯的来源。表中逐项展示的币种舍入差用 **Display rounding** 单列。
