## 共用数据与交互

[虚构数据](demo-data.json) 以 P01 的现金流算例放大 1,000 倍作为基线，收入为 300,000 元，全成本经营利润为 24,000 元、利润率为 8%。项目第 0、1、2 期现金流为 −100,000、60,000、60,000 元，年折现率为 10%。

同一变更为两人装配工序 CT 从 30 增至 36 秒，每循环一件，效率 100%，小时费率 60 元，第 1 年良品数 10,000。单件人工从 1.00 增至 1.20 元，年度人工增加 2,000 元，假设税及库存等其他变化为零、在第 1 年末支付。因此经营利润为 22,000 元，利润率 7.33%，NPV 为 2,314.05 元，IRR 为 11.71%，回收期 1.70 年。资金峰值仍为 100,000 元、首次第 0 期。

六组卡均列出批准基线 B01、当前预测 F02 和差额。两版收入与资金峰值差额为 0。有利差用绿色加文字，不利差用红色加文字。预览以 B01 为比较对象，默认 CT 36 秒，改为 24 秒可看有利情景。控件演示范围为 1–60 秒。

三个具名报告可打开预算、现金流或版本差异摘要。点击 NPV 等信息按钮可读 P01 的英文释义，Esc 与关闭按钮返回。十个模块入口展示模块位置与同项目上下文，制造人工入口可打开同一预览。这些操作支持视觉选稿。

## 核验与决策

浏览器为本机 Chrome，逐稿检查桌面及窄屏、六组数值、CT 不利及有利预览、报告弹窗、释义、控制台错误和页面横向溢出。结果见 [界面验证](visual-checks.json)。使用随 Codex 提供的 Node、Playwright 和 Sharp 在本机重跑截图的命令为 `node docs/validation/project-finance/P02/capture.mjs`。
