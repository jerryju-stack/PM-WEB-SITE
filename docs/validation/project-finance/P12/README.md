## 口径和审批

- 项目选择已配置的预算币种和精度、含税或未税、服务验收／货物收货／发票审核，并记录依据。合成 T6 采用 CNY 两位、未税、服务验收。另一个项目在浏览器建立 JPY 零位、含税、发票审核口径。金额按对应精度存储。
- 成本范围有稳定编号，可指定产品或建立项目共用范围。预算拨款和成本都先提交为草稿。预算编辑角色可以提交、修改及撤回草稿，具有 `financeApprove` 的角色可以独立确认，且提交或编辑过原草稿的账号不能确认该行。已确认金额通过另建凭据更正，原行与审批证据可追溯。
- 发生及付款使用独立的类型、日期、期间和凭据。付款与带符号的调整分别关联已确认的原始发生行。跨期调整按自身的会计期间列示。付款表按结算期汇总，预算实绩按已确认发生及调整汇总。
- P04 的版本修订、审计快照、永久操作者和幂等回执直接复用。共用影响面板以同一修订预览并保存。冲突要求重新读取，丢失确认响应可用原请求重试。每次提交、重试和读取均重查当前权限。冻结版本保持原账表。
- 现有版本的 P04 预算汇总可继续查阅。启用 P12 后，执行金额来自按新项目口径录入并确认的范围凭据。旧版事件保留来源，由项目责任人在建立正式口径时核对采用。

## 账表公式

| 指标 | 计算或范围 |
|---|---|
| 按已确认成本的预算余额 | 批准预算 − 已确认发生净额 |
| ETC | 一个范围、一个当前截止期的录入剩余数，扣减同范围在截止点之外计入的确认成本净额，最低为零 |
| EAC | 已确认发生净额 + 扣减后的 ETC |
| 预计完工差额 | 批准预算 − EAC |

设置 ETC 时记录截止期与当时的审批顺序。发生于截止期之后的工作、以及截止期之内但之后才确认的工作，都消耗该范围的 ETC。关联到已包含在截止点内的旧发生行的更正调整实绩。关联到截止点之外的发生行的更正也重算该发生行已消耗的 ETC。完成的范围可明确输入 ETC 为零，缺预测的范围会显示不可计算。草稿成本单列。

**Change Impact** 分开显示预算执行差额、项目经营利润、项目现金流和 NPV。P12 预算凭据影响执行账，项目经营预测通过对应业务驱动变更。T6 的确认、付款、跨期调整预览均验证了经营利润、项目现金流与 NPV 的零差额。
