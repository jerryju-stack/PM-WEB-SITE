# Batch E-C：查询、排期与交互优化

记录日期：2026-11-16（Asia/Shanghai）。在 `ac2b273` 的 E-A/E-B 代码上继续，只操作本地隔离合成数据。当前 E3 与 E4 后端实现及自动回归已有证据；E4 浏览器输入预算和分页完整用户路径仍须在 E5 闭环，不能把本文当作 E 全部验收通过。

## 代码与接口

- `timingVersions.page()`：只投影元数据，SQL 排除软删除，以 `(saved_at DESC,id DESC)` 稳定排序，默认 50、上限 100；带 scope 的不透明游标拒绝跨项目使用。新增迁移 9 的双表分页索引。
- 历史、比较选择和导出选择都提供“加载更多”，追加页去重；历史删除/撤销重新读取第一页，后续页仍可加载。旧 `list()` 仅为离线兼容的全量元数据读取，生产 HTTP 使用 `page()`。
- 迁移 9 为旧快照建立内容指纹侧表。正常保存/归档/采用在同一事务登记指纹，采用仅解析相同指纹的候选，并继续执行最终语义比较。强制指纹碰撞、缺失旧索引、项目元数据变化、软删除/撤销有回归。未知离线插入可一次补索引；不会把碰撞直接判为等价。
- 迁移 10 创建独立 `projects_cards/articles_cards` 投影，回填不改资源版本或审计；INSERT/UPDATE 触发器覆盖资源写入、旧 JSON 种子及 Timing 派生进度。首页 SQL 读取投影及小型标量列，不读取正文再删字段。
- `/api/data?limit=24&q=...&status=...&category=...&projectsCursor=...&articlesCursor=...` 返回摘要、各自 nextCursor 和授权范围内统计；正文由指定资源 GET 读取。首页 `users=[]`，管理页面按需调用 `/api/users?limit=24&cursor=...`。保留仅 admin 可用的无参数账号列表兼容入口。
- 权限上下文只在同步请求内建立一次：账号、组、成员与可见性快照不跨请求、不跨 await；分页及统计先按权限过滤。搜索对摘要字段做 Unicode 小写匹配，支持非 ASCII 大小写；文章正文不作为卡片搜索源。
- 前端首页/文章详情/编辑/搜索/筛选/管理页、文章新建时的项目选择均消费新接口；Timing 直达页编辑项目信息按 ID 读取，避免项目不在第一页时误开新建表单。
- E4 使用单快照任务/父子/WBS 索引，工作日按整周跳过后计算余数，保留原 FS、日期界限和 BigInt 精确进度。SQLite 连接复用语句，任务所有权批量检查、旧任务审计用 Map 查找。

## 隔离基准

Node v24.22.1，Windows 10.0.26200，AMD Ryzen 7 9700X；与 E-A 相同 `syntheticTasks`。每组记录第一次调用和 30 热样本，P95 为排序后 `ceil(n*0.95)`。采用时间每个矩阵格一次，**不是采用 P95**。源数据及临时目录见 JSON。

| --- | --- | --- | ---: | ---: | ---: |
| 100 / 100 | 102 / 3,406,700 | 1 / 0 | 6.94 / 8.21 | 0.241 / 0.369 | 14.30→8.27 |
| 100 / 1000 | 1002 / 34,448,000 | 1 / 0 | 75.53 / 78.75 | 0.190 / 0.218 | 68.53→9.16 |
| 1000 / 100 | 102 / 34,666,700 | 1 / 0 | 66.56 / 67.11 | 0.142 / 0.148 | 163.00→67.70 |
| 1000 / 1000 | 1002 / 350,648,000 | 1 / 0 | 695.48 / 725.64 | 0.168 / 0.217 | 595.83→69.93 |

新列表每页 50 条；旧行为无分页。因此返回字节从最后一格 262,894 降至 13,315。完整页遍历正确性由回归验证，不能用截断丢历史来换性能。旧进程 maxRSS 3,721,752,576 bytes，新 292,950,016 bytes；这组对比包含历史列表放大，和 E-B 仅文件场景的 RSS 不是同一负载。

500 篇文章、每篇固定 12,000-byte 正文：首页响应 6,099,797→8,302 bytes；热 P95/max 62.45/142.63→2.626/2.649 ms。新测试仍返回授权统计与 24 条文章摘要，正文单独读取。独立 SQL 回归核对摘要查询不包含资源 data/snapshot，并验证返回字节和撤权后的下一页及计数。

算法独立同进程对比冻结的 `ac2b273` 参考代码：1000 项链式 P95 18.42→10.03 ms，扇出 17.49→9.48 ms，长工期 141.04→8.85 ms。1000 项 XML 预览 P95 492.84→83.01 ms。预览比较使用相同当前解析器/排期器/比较器，只对照旧/新匹配算法；不把它声称为整个 E0 文件管线对比。参考文件仅用于回归，产品不导入它们。

原始证据：[before.json](validation/batch-e-c/before.json)、[after.json](validation/batch-e-c/after.json)、[algorithm.json](validation/batch-e-c/algorithm.json)。`query-after.json` 是 E3 中间复测，最终数字以 after.json 为准。
