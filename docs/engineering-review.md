更新日期：2026-10-26（Asia/Shanghai）

A–C 已完成线上部署。后续直接复用已有排期、权限、审计和备份基础，按业务功能推进。完整可靠性检查集中在本轮全部功能更新完成后进行，各批只检查本批功能是否可用及直接相关的修改。

## 1. 精简后的批次

执行顺序：**D Timing → E 8D / Lesson Learn → F 语言与主题 → G 项目模板 → H 财务 → 统一收尾验收**。

| 批次 | 目标 | 本批交付顺序 |
| --- | --- | --- |
| D | Timing Plan 升级及输入输出 | 版本历史与比较 → Excel/PDF 导出 → Excel 导入 |
| E | Lesson Learn 升级为 8D Report 及输入输出 | 8D 编辑与流程 → PPTX/PDF/Excel 导出 → 8D Excel 模板导入 |
| F | 语言与主题 | 中英文切换、明暗主题及偏好保存 |
| G | 项目模板 | 模板管理、模板版本、按模板创建项目 |
| H（最后一个功能批次） | 财务模块 | 单独定义需求后实施，具体范围在本批开始时确定 |
| 统一收尾验收 | 全部更新的完整检查 | 全站流程、权限、并发、迁移、备份恢复和必要性能检查 |

原 I 批次取消，导出功能分别并入 D、E，并补充各自的导入功能。每个模块升级后立即完成自己的输出和输入，再进入下一批。原 D0 的独立可靠性前置批次取消，遗留检查并入最终验收；重试防重复等处理随涉及的保存/导入功能实现。

## 2. Batch D：Timing Plan 升级、导出与导入

### D1：版本历史与比较

- 仅保存三类完整计划快照：基线、PM 明确标记的 V1/V2 等序列版本，以及最终版本；记录保存人、时间、版本名称和修改原因。
- 普通保存只更新当前计划，不生成完整历史快照；导入后的普通保存也遵循此规则。现有修订号继续用于并发控制。
- PM 可将当前计划保存为上述版本。版本页可查看已保留版本的任务表与甘特图，比较日期、工期、负责人、依赖、任务增删和里程碑变化。
- 当前计划、基线、V 序列版本和最终版本清晰区分；已保存的版本只读，后续修改保留在当前计划，待 PM 再次明确保存版本。已有项目不补造过去历史。

### D2：优先完成输出

- **Excel：**导出当前计划或指定历史版本，包括任务层级、责任人、日期、工期、进度、里程碑和依赖；提供版本信息及变更对比表。
- **PDF：**导出任务表与甘特图，适合评审和分享，带项目、版本、生成时间与分页表头。
- 导出使用选定版本的数据，内容与页面一致。Excel 同时提供可再次导入的标准模板。

### D3：完成输入

- 支持按标准 Excel 模板导入任务、层级、日期、工期、进度和依赖，可用于建立新计划或更新现有计划。
- 导入前预览新增、修改和删除项；未出现在文件中的任务默认保留，删除必须明确选择。
- 更新现有任务通过系统 ID 匹配，新增任务生成新 ID；人员或依赖无法匹配时列出待处理项。
- 确认后一次保存为当前计划的新修订，已保留的基线、V 序列版本和最终版本不变；是否另存版本按 D1 规则处理。重复提交不重复创建；文件错误先提示修正。

**本批完成标准：**PM 能保存多个版本、查看差异、导出指定版本，并把标准 Excel 编辑后重新导入为新修订。历史计划恢复为新草稿按实际需要补充，不作为本批前置。

## 3. Batch E：Lesson Learn 升级为 8D Report、导出与导入

### E1：完成 8D 报告功能

依据用户提供的 PPT，建立结构化报告，包含报告编号、项目、产品、客户、零件号、失效模式、测试过程及负责人。

| 8D 步骤 | 主要内容 |
| --- | --- |
| D1 团队 | 姓名、岗位/部门、联系方式、角色与职责 |
| D2 问题定义 | 问题描述、发生时间、项目/产品/客户信息和问题图片 |
| D3 临时围堵 | 围堵措施、地点、数量、检验/不良数量、责任人、完成时间和有效率 |
| D4 根因分析 | 人机料法环测分类；发生、检出、系统三条 5 Why；调查行动和根因验证 |
| D5 永久纠正措施 | 根因对应的措施、责任人、期限及验证结果 |
| D6 实施与有效性 | 实施日期、结果、有效率及证据 |
| D7 防止再发 | 系统预防、横向推广和 Control Plan、作业指导书、图纸、DFMEA/PFMEA 等文档更新 |
| D8 认可与经验总结 | 团队认可、经验总结、适用范围和完整报告归档 |

支持图片/证据附件、行动责任人与到期日，以及草稿、处理中、待审核、已关闭和重开。旧 Lesson Learn 保留并可转为 8D 草稿；关闭后的经验可检索复用。完整报告与公开经验摘要按现有项目权限分别管理。

PPT 中的岗位和 30 分钟、7 个工作日、30 天作为模板参考，是否强制执行在本批开工时确认。

### E2：优先完成输出

- **PPTX：**按参考 PPT 的 D1–D8 结构输出报告，支持汇报、客户沟通和后续编辑。
- **PDF：**输出完整报告、图片、措施、验证和审核信息，用于归档与分享。
- **Excel：**输出可编辑的结构化报告及行动清单，同时作为标准导入模板。
- 可以选择明确的报告版本；未关闭报告在输出中标识为草稿或处理中。

### E3：完成输入

- 提供 8D Excel 模板，支持团队、问题、围堵、根因、措施、验证、预防和经验总结的结构化导入。
- 支持将本系统导出的 Excel 修改后重新导入；预览字段和行动变化，确认后保存为新草稿/新修订。
- 图片和证据可在报告内补充上传；已有 PPT/PDF 可作为原始报告附件保存。首期结构化导入以标准 Excel 为准，任意版式 PPT/PDF 自动解析不纳入本轮。
- 导入内容沿用本系统审核流程，不自动获得“已审核/已关闭”状态；原报告及其历史保留。

**本批完成标准：**完成一份包含图片和措施的 8D 报告，能够输出 PPTX/PDF/Excel，并通过 Excel 模板导入或更新报告，原 Lesson Learn 仍可访问。

## 4. Batch F：语言与主题

实现中英文界面、明暗主题和偏好保存，覆盖 Timing、8D、管理页面及导入导出入口。语言切换不改用户填写的正文；日期与数字按统一规则显示。建议登录用户按账号保存偏好，访客按设备保存。

**本批完成标准：**切换后页面正常、刷新保留偏好，主要表格、甘特图及报告内容清晰可读。

## 5. Batch G：项目模板

支持维护不同项目类型的阶段、任务、工期、依赖和里程碑模板。模板可保存版本，创建项目时选择模板版本和起始日期。模板更新不自动修改已建项目；现有八阶段模板继续可用。

**本批完成标准：**可建立两种模板并分别创建项目，生成正确的任务层级与依赖，且与 Timing 历史及导入导出衔接。

## 6. Batch H：财务，最后单独实施

开始前单独明确预算、成本、采购/付款、收入/利润等实际范围，以及币种、金额精度、税率/汇率、审批、锁期、更正、权限和报表口径。随后按确认范围完成数据、流程、导入导出及报表，不提前把未定义的财务功能混入其他批次。

**本批完成标准：**按单独财务需求完成业务流程，明细与汇总一致，具备所需权限和追溯信息。

## 7. 检查与交付方式

- **开发期间：**每批只做必要的功能、类型及直接相关检查；发现影响正常使用的问题及时修复。复用 A–C 已有权限、并发、迁移和备份机制，不反复重做全套可靠性演练。
- **全部更新完成后：**统一进行一次完整验收，覆盖全站业务流程、Timing/8D 导入导出往返、权限与并发、旧数据迁移、数据库与附件备份恢复、遗留原生离开提示及必要容量检查，集中修复问题。
- **交付记录：**每批简要记录完成内容、功能检查及剩余项；重要更新按 AGENTS.md 创建清晰 Git commit。部署时保留必要备份，完整可靠性验收集中收尾。

实时通知、阶段级权限、外部告警/自动异地同步等原选配项保留在后续待办，按实际需要另行安排，不再增加本轮独立批次。
