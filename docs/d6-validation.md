# D6：甘特图全项目缩放

2026-10-30（Asia/Shanghai），本地实现；未推送、未部署。

- 入口：Timing 甘特图右上角原有「日 / 周 / 月」旁新增「全项目」，沿用选中样式并提供 aria-pressed。仓库实际已有三档为日、周、月，默认周视图保持原样。
- `src/timing.ts`：基于全部任务有效开始/结束日期计算范围，包含结束日并增加两侧留白，使用右侧时间轴 clientWidth（已扣除任务栏和纵向滚动条）。折叠不改变范围，日期刷新后重新计算。任务、里程碑、依赖线及拖动换算共用时间坐标。
- 时间刻度按空间选择日、周、月、季度、年或多年，顶部显示年份范围。空项目及无有效日期使用项目开始日期或今天。短条最小宽度及里程碑大小沿用；过窄刻度不显示文字，汇总名称限制于可用空间。
- ResizeObserver 只重绘右侧时间轴，保留左侧输入、字体、行高及纵向滚动位置；拖动中延后适配。全项目期间禁用时间翻页及今天按钮，切回原档恢复。
- `src/timing.css`：仅增加全项目刻度网格和横向溢出裁切；跨多年时不生成密集逐日背景。

验证：`node --experimental-strip-types --test tests/timing-fit.test.ts` 两项通过；`tsc --noEmit` 通过；`git diff --check` 通过。定向测试覆盖空数据、缺失/无效日期、单日、2000–2100 年跨度，以及实际渲染器和事件处理器的全项目显示、折叠、日期刷新、640→360 像素适配、纵向位置保留、切回日/周/月的原始宽度。首次功能测试因夹具在初始化前设置滚动位置而失败，修正夹具后针对性复验通过。

功能确认使用轻量 DOM 夹具，未执行真实浏览器布局/目视验收：工具报告 Work 设置禁用了本地浏览器。未运行全项目回归、独立 code review 或全仓审查；未修改 Excel 导入导出及业务数据。
