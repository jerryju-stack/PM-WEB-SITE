# Batch D2/D3 实施与联合验证

2026-10-27（Asia/Shanghai）。本地实现完成，未部署线上。范围以本轮用户提示为准；附件历史建议仅作背景。读取了仓库 AGENTS.md，核对 D1 快照、权限、任务写入及版本比较后继续开发。

## 实现与操作

1. 项目 **Timing → 导出 / 导入**，选择服务器当前计划、基线、V 序列或最终版本，点击 **导出 Excel / 导出 PDF**。下载不包含页面草稿，不新增保留版本。历史直接读取 D1 快照；不调用网站排期器。当前状态日期固定为北京时间导出日期，历史固定为保存时间的 UTC 日期，与 D1 页面口径一致。
2. **下载原始模板** 返回附件原文件。新计划先通过现有页面创建项目，再选择 **建立新计划**，仅允许空计划或未经编辑的默认八阶段；更新已有任务使用 **更新现有计划**。
3. 在 Excel **任务编辑** 黄色区编辑 WBS、任务名称、负责人、输入开始/结束、输入完成度、前置任务 WBS、叶子类型及操作。完成度填 `50%`；多个前置 WBS 用逗号分隔。灰色 F、K–P 列由公式计算，导入不信任其缓存或手工修改结果。导出文件的 WBS 和前置 WBS 使用文本格式；原始模板的前置列输入 `1.10` 时可加英文单引号，防止 Excel 自动转数值。
4. 上传 `.xlsx`（最大 8 MB）→ **生成导入预览**。缺少可信身份的行逐项选择新增或现有任务，再重新预览。核对输入日期与网站最终日期、字段/层级/依赖变化及删除影响，勾选核对声明后 **确认导入当前计划**。网站仍按现有工作日与 FS 规则顺延；Excel 本地不自动按依赖排期。

接口：`GET timing/template`、`GET timing/export?version=current或版本ID&format=xlsx或pdf`、`POST timing/import/preview`、`POST timing/import/confirm`，均位于 `/api/projects/:id/` 下。读取复用项目 Timing 权限；预览和确认复用 `timingEdit`。

## 模板主要特性

| 特性 | 保留与必要处理 |
| --- | --- |
| 工作表 | 名称、顺序、用途不变；排期计算仍为 veryHidden，无新增可见表或技术列 |
| 标题和框架 | 填入所选版本项目名称；第 9 行原 16 列表头、第 10 行数据起点及 TimingTasks 表保留；演示任务与未使用 DEMO 字符串清除 |
| 外观 | 原 styles、字体、颜色、边框、列宽、合并、日期/百分比格式、行高保留；超过原 20 行时复制输入/计算格式及行高，最多 100 项；前置列复用原有文本样式防止 1.10 变 1.1 |
| 原生设置 | 冻结窗格、说明折叠、隐藏列、下拉、条件格式、计算表保护、打印方向/缩放/纸张/边距和打印机设置保留；延伸表与条件格式范围，打印范围随计划调整，并重复表头及左侧标识 |
| 公式 | 共享公式展开为等价独立公式；不替换成静态结果。保留输入/计算分工、删除排除、汇总、显示过滤、状态及甘特条件格式 |
| 规则衔接 | 汇总完成度按所有叶子权重计算后取整，与网站一致；有日期的一级无子任务项可为普通任务/里程碑，说明区同步解释；本地依赖仍仅展示 |
| 时间控制 | 原日/周/月/全项目、起点策略、偏移、手动起点、状态日期和层级控制继续引用公式；长于约 96 周的计划初始使用全项目刻度；历史不保留会漂移的 TODAY 状态口径 |
| 缓存 | 服务端执行模板闭合公式词汇计算，填写全部公式缓存，并与所选任务类型、日期、工期、进度逐项核对；另设打开重算。不是只依赖重算标志 |
| 稳定身份 | 来源项目/修订/版本置于自定义文档属性；签名任务身份附在 P 列计算单元格的内部自链接属性，沿表格排序/插行移动，无新增列。输入区可改 WBS、名称、负责人；清除计算格链接后须显式匹配，不按行号或名称猜测 |

保存仍复用 `store.saveTasks` 的权限边界、任务 revision、排期、审计和附件清理事务。迁移 006 保存临时预览及确认回执；预览有效 24 小时，过期未确认数据在下一次预览时清理，成功后清空任务载荷。确认按同一用户、项目、预览 ID 幂等；revision 或项目 version 变更返回 409，须重新预览。确认只增长当前修订，不创建 D1 快照；已有备注、暂停状态、未承载字段与保留任务附件不被清空。

## 实际联合验证

- 类型检查及 Git 差异空白检查通过。直接相关自动检查共 **30 个不同测试通过**：D2/D3、D1、排期及 HTTP 写入 21 个，迁移和事务兼容 9 个；受后续 XML/字体/预览修改影响的用例单独补验。最初回环 EACCES、临时文件 rename EPERM 在允许的隔离执行环境复验通过，没有删除断言或跳过失败。
- 自动覆盖：当前/历史导出隔离、WBS 1.10、日期/百分比、公式缓存、里程碑、原始模板新计划、无标识显式匹配、字段错误、缺父项、重复 WBS、依赖解析、100 项末行完整导入及格式、101 项拒绝、删除父项/依赖、缺行保留、备注/附件保留、往返再导出、冲突、重复确认、审计失败回滚、只读账号及 D1 数量不变。模板主题/样式/打印机二进制及窗格/列宽/合并/保护/页面设置逐项比对。
- **Microsoft Excel 实操**：打开导出副本无修复提示；把普通任务完成度 25% 改为 75%，日期改为 10/29–11/06，工期变为 7，汇总完成度变为 73%，结束随之改变；保存后读取三表缓存均无公式错误。实际插入表格行、填写新任务、标记删除、降序排序；视图仍按 WBS 汇总排序。月刻度与仅 1 级实际生效，月日期缓存从 46296 到 46327（10/1 到 11/1），显示 WBS 仅 1、2、3。
- 原生验证发现重写 WBS 会移除该输入格的链接，已修复为 P 列载体；另开副本同时修改 WBS/名称/负责人、插行和排序后，7 个原任务身份全部保留，任务 b 对应新 WBS 1.5。见 [原生保存结果](validation/batch-d2-d3/native-results.json)。
- **真实浏览器**：完成当前 Excel 下载、上传修改文件、选择新增匹配、预览新增 1/删除 1/修改 3、核对 FS 顺延及删除依赖、确认；当前修订 1→2，基线数量仍为 1。重新打开基线任务表/甘特图仍为旧内容，D1 比较正常；成功下载指定基线的 Excel/PDF。截图：[比较结果](validation/batch-d2-d3/browser-comparison.jpg)、[导入后当前计划](validation/batch-d2-d3/browser-roundtrip.jpg)。
- **PDF**：A3 横向矢量条形和可搜索文字，嵌入 OFL 中文字体；样例人工查看，中文、行和条形对齐。70 项、约 19 个月、长中文名称生成 25 页，全部页有表头，文本提取覆盖全部 70 项。渲染检查发现首版页脚重叠后已修正分页预算并重新检查首末页，页脚与任务区分开；完成/逾期/里程碑均有实际渲染。

## 实际限制

- 本轮保留模板 **三级、100 项** 的计算上限，未宣称扩容。更深/更多任务明确拒绝 Excel 导入导出，不截断；PDF 单独分页。模板无法无损表达的保存结果（如无日期但有工期/权重的叶子、非一级空汇总或不符合模板汇总的旧快照）导出明确报错，PDF 仍可输出原始快照。不会用当前网站规则改写历史。
- Excel 的状态仍按模板日期和进度显示，未增加暂停输入列；网站已有暂停状态在导入合并时保留。原始模板没有网站 FS 自动排期能力，必须核对网站预览后确认。
- 原生检查使用测试工作副本；最终样例另经文件/缓存自动检查。实际打开过打印预览，确认 A4 横向和原缩放设置；未进行实体打印，未遍历每种起点/偏移/手动日期组合或所有 Excel 版本。后续界面被最小化且工具检测到人工输入，未继续抢占桌面；不将这些未执行分支写作通过。切换时间窗口后可在 Excel 打印预览中按需要调整打印范围。
- 文件往返通过自动测试与浏览器分别验证；浏览器上传文件的输入修改由 OOXML 测试工具准备，Excel 原生修改/插行/排序由独立实操验证，未混称为同一次全程人工操作。未做全站安全审查、灾难恢复演练或容量认证。

交付样例：[Excel](samples/timing-d2-d3-baseline.xlsx)、[PDF](samples/timing-d2-d3-baseline.pdf)，均来自隔离验证项目“动力总成支架开发”的设计评审基线，不是线上生产数据。线上部署及迁移另行安排。
