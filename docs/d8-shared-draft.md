# D8：共享草稿与单人编辑

每个项目只有一份服务器持久草稿，与正式执行计划和编辑租约分别保存。进入编辑继续已有草稿；采用后删除待采用草稿，下一次修改从最新执行计划建立新草稿。采用不退出编辑、不释放租约、不移动基线。

- 自动保存：输入停顿 800 ms 后保存，保留失败输入并提供重试。采用前先完成当前输入保存，再按草稿 ID / 修订采用。未送达服务器的数据不会显示为已保存。
- 编辑租约：30 秒有效期，每 8 秒心跳。页面退出、关闭、路由卸载主动尝试释放；断网、崩溃由超时兜底。断网时取消前端未完成的排期请求；恢复后需重新点击“编辑计划”，重新读服务器状态，不自动重放旧输入。
- 所有任务写入、甘特拖动、任务增删和 Excel 导入均要求有效租约、草稿 ID 和草稿修订。相同账号的不同页面也不能共用占用；租约 token 不在只读状态接口返回。旧会话无法写入、续期或释放新占用。
- 从历史建立草稿时，只采用历史任务安排；相同稳定 ID 的进度和状态取当前执行值。浏览和比较历史不替换草稿。替换已有草稿时可归档为“未采用”、放弃或取消；归档与替换在同一事务中完成。
- 采用事务包含执行任务更新、必要的原计划归档、新 V 版本、来源记录和草稿采用回执。失败整体回滚。以草稿 ID 幂等防重复；内容无变化不新增正式版本；已有相同正式记录时不重复归档原计划。
- 未采用草稿和原执行计划记录只读，进入同一版本查看、比较和导出入口；未采用记录不分配 V 编号。原有基线 / V 序列 / 最终版本保持只读。
- 采用时移除的任务保留为不可见的关联占位记录，附件与文件保持存在；按原任务 ID 恢复任务后可再次访问其附件。新草稿任务在采用后可上传附件，现有执行任务的附件操作保持独立。

数据库升级为迁移 7，不为既有项目补造版本或草稿；备份检查兼容新表和旧数据。没有新增运行时依赖。

验证涵盖共享草稿持久化与隔离、租约过期及旧会话隔离、原子采用与失败回滚、幂等和无变化、历史起点归档 / 放弃、稳定 ID 进度继承、附件保留，以及现有排期、版本、导入、迁移和备份回归。浏览器使用隔离本地数据验证了即时输入一键采用、保持编辑、第二页面只读及拒绝占用、退出后继续、历史三选项切换。本次仅完成本地开发，未部署。
