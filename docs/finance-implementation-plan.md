## 首页汇报口径与命名

首屏顶部固定项目、批准基线、当前版本、数据截止期和显示币种/单位。第一行回答盈利与投资回报，第二行用累计现金流标出资金最低点和回正期，旁边显示金额影响最大的差异。下方有预算执行摘要（批准预算、已确认实绩、剩余预测、预计完工差额）以及预算执行、项目回报、版本差异三个具名报告入口。详细假设由业务板块承接。

### 六组常显指标

| 显示名 | 中文释义与口径 | 点击后看什么 |
|---|---|---|
| Revenue · 营业收入 | 项目全生命周期各产品分期营业收入合计，注明币种及金额单位。 | 按期间、产品、市场查看销量、售价和年降。 |
| Operating Profit / Operating Margin · 经营利润及利润率 | 全成本管理口径经财务映射后显示。利润率按同范围利润合计除以收入合计。历史 CQA 的 MPBITRI 先以原口径显示，映射待定时标准指标注明“待核对”。 | 收入到利润的分项变化以及原表口径。 |
| NPV · 净现值 | 按项目折现率将各期项目现金流折回起算时点，计入第 0 期投入。 | 逐期现金流、折现率、折现期及各期现值。 |
| IRR · 内部收益率 | 使项目净现值为零的折现率。由合并后的逐期现金流求解。 | 现金流序列及求解状态，包括无可解释的唯一解。 |
| Payback Period · 投资回收期 | 按约定的未折现累计项目现金流回正时间，以年显示。示明起算期、期间内插值与全期未回收的处理。 | 累计现金流、回正前后两期与计算依据。 |
| Peak Funding Requirement · 峰值资金需求 | 从第 0 期起累计项目现金流的最大缺口，以正金额显示，并列出首次出现的期间。 | 现金流最低点、当期投资付款、补偿回款与营运资金。 |

每卡并列**批准基线、当前预测、差额**，预览时另标候选值。金额差保留币种与符号，利润率和 IRR 的绝对差用“个百分点”，回收期差用年或月。空值、无业务、零值、未回收及口径待核实分别显示。项目 NPV、IRR、回收期、资金峰值由同币种同期间的项目现金流统一计算。项目利润率按分子分母合计计算。

**通用财务名称优先。** 字典为每个指标管理稳定键、中文名、通用英文名或缩写、中文释义、单位、期间、公式、数据源及版本。次级指标包括 EBIT（息税前利润）、NOPAT（税后经营利润）、CAPEX（资本性支出）、NWC（净营运资金）、FCFF（企业自由现金流，注明项目适用口径）、ROIC（投入资本回报率）、EAC（预计完工成本）、ETC（剩余完工成本估算）。原表另保留 DVP（直接变动利润）、MPBITRI（CQA 管理利润）、ROS（销售回报率）、ROAE（平均占用资产回报率）和 EVA（经济增加值）。财务校准各自的成本、税和资本口径。ROAE 与 ROIC、经营利润与 EBIT 分别定义。工程字段也入字典，例如 CT（工序周期时间）、Takt Time（需求节拍）、OEE（设备综合效率）。

**释义是交互功能。** 指标卡、图例、表头、编辑字段和差异面板从同一字典取词。鼠标悬停与键盘聚焦信息按钮均显示中文，触屏点按可读，Esc 或关闭按钮可收起，焦点回到触发处。以 NPV 为例，先说清“按当前折现率，未来现金流折合今天值多少钱”，再给出本项目折现率、币种、期间与数据来源。关键状态和单位始终可见。[W3C 的悬停与聚焦内容说明](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus)

## 每次改数，怎样看见最终影响

1. **编辑时**，旁边固定「本次变动影响」面板，窄屏用可展开底栏。第一行列出改了哪个字段、旧值、新值、单位、来源和生效期间。支持单项修改、批量导入、工程实测、实际成本入账及回款日期变更。
2. **预览时**，同一计算服务基于原版本和候选变更重算，逐项显示“更改前 / 更改后 / 差额”。面板默认对比本次编辑前的版本，另可切换到批准基线，两处都显示比较对象。用可点的步骤展示因果关系，例如「工位 CT → 每件人时 → 单件人工 → 年度经营利润 → 分期现金流 → NPV」。同时叠加两条累计现金流曲线，标出最低点、回正期，以及受影响的产品与年度。
3. **解释时**，金额差用瀑布图分解，并给出同数据表格。明确基线、归因顺序、共同影响与剩余未解释额，所有金额能对回总差。IRR 等比率展示重算值及百分点差。改备注显示“财务指标无变化”。缺少费率或口径时显示受影响指标与待补字段。
4. **保存时**，撤销候选变更可恢复原值。保存草稿后从对应版本打开同一结果，采用为当前预测或批准基线属于明确的不同动作。记录变更人、时间、原因、来源和修订号。并发修改、连续编辑造成的旧响应或计算失败须有明显状态，最新输入与当前显示结果要能对应。

## 可独立复算的验收例

以下均为**脱敏测试输入**，金额单位为元，百分比与金额在展示时舍入。按给定前提断言变化，每例另核对合并项目现金流。实际 CQA 对表使用 P01 冻结的口径及本机原件。

| 编号 | 输入与动作 | 必须观察到的结果 |
|---|---|---|
| T1 回报 | 第 0、1、2 期现金流依次为 −100、60、60，年末流入，折现率 10%，期间内按线性回收。 | NPV 4.13，IRR 13.07%，回收期 1.67 年，峰值资金需求 100，发生在第 0 期。 |
| T2 制造人工 | 单工序、两人、每循环一件良品，人工效率 100%，费率 60 元/人时。CT 从 30 秒改至 36 秒，第 1 年合格产量 10,000 件且产能够用。增量成本于第 1 年末支付，税、库存等其他变化为零，折现率 10%。 | 每件人工 1.00 → 1.20，年度直接人工增加 2,000，经营利润和第 1 年现金流各减少 2,000，项目 NPV 减少 1,818.18。 |
| T3 BOM | 零件每件产品用两件，单价上调 1 元，有效期内生产且销售 1,000 件。其余条件固定。 | 单件材料增加 2 元，该期直接材料增加 2,000，经营利润减少 2,000。能回到料号、价格版本和生效期。 |
| T4 样机与复测 | 需 10 件样机，每件 300 元。基线已购买的固定价试验包包含其中 4 件。新购 6 件，另增加一次 2,000 元复测。当期确认并支付，无额外补偿。 | 新增样机支出 1,800，复测 2,000，合计新增开发支出及当期现金流出 3,800。试验包中 4 件可追溯。 |
| T5 回款时间 | 第 0 期支付设备 10,000，客户补偿 10,000 从第 1 年末推迟至第 2 年末。折现率 10%，其余现金流、应计收益和折旧固定。 | 总投资与补偿合同额差额为零，第 1 年少收 10,000，第 2 年多收 10,000，NPV 减少 826.45。该简例的缺口峰值同为 10,000，占用时间延长一年。 |
| T6 预算 | 批准预算 1,000，已确认 400，草稿 50，ETC 500。 | 已确认实绩 400，按已确认成本计算的预算余额 600，EAC 900，预计完工结余 100。草稿 50 单列。确认或调整后可重算并追源。 |

**网站端的完成条件**　管理员能从一级导航打开一个已有项目的财务首页，在原页面复核核心值并往返三个报表。工程人员能以实测工时替换设计假设，开发人员能录入一批样机和一轮复测，财务能追溯一笔设备付款或补偿。三种角色的变更都能在同一套预览和版本比较中解释清楚，且已批准历史可重现。

**后续企业接入**　数据库保留数据源标识、外部键、期间、原币/本位币、来源修订与财务口径版本。以后接企业 SAP 时在此对接凭证、匹配和对账。Power BI 从已授权的只读汇总口径取数。企业字段核验、连接与网关、租户刷新、Viewer 身份验证继续作为后续工作。
